# NOVA Premium ⚡

> نظام NOVA — أداة متكاملة تُقدّم تجربة مُحسّنة لإدارة ونشر الإصدارات.

---

## 🌌 لمحة عن المشروع

NOVA Premium هو مشروع قيد التطوير يهدف إلى تقديم مجموعة من الأدوات والميزات المصممة لتسهيل إدارة النسخ والإصدارات ضمن بيئة سطح المكتب/الخادم. يتم تطوير المشروع بلغة C# ويجمع بين الأداء وسهولة الصيانة.

## 🔧 حالة المشروع (التقدّم)

- نسبة الإنجاز الحالية: **80%**
- الأولوية الآن: إصلاح الأخطاء الصغيرة، تحسين واجهة الاستخدام، وتجهيز الحزم للإصدار الرسمي.
- خارطة الطريق القادمة: استقبال ملاحظات المستخدمين، إضافة تحسينات بناءً على الاقتراحات، وإطلاق نسخة مستقرة على Itch.io.

> ملاحظة: مواعيد الإصدار تُحدَّد وفق خطة التطوير ولا تُنشر دائماً فوراً؛ سنعلن عن الإصدارات الرسمية عبر قنوات الدعم الرسمية.

## 🛠️ كيف تساهم بالملاحظات أو التقارير

نرحّب بملاحظاتكم واقتراحاتكم لتطوير المشروع. الرجاء اتباع الخطوات التالية لإرسال ملاحظات بنّاءة:

1. انضم إلى سيرفر Discord الخاص بالمشروع عبر الرابط أدناه.
2. استخدم القناة المخصصة للاقتراحات أو التقارير.
3. اذكر الخطأ أو الاقتراح مع خطوات إعادة إنتاجه أو وصف الوظيفة المطلوبة.

نرجو الاحترام المتبادل داخل المجتمع؛ أي سلوك غير مناسب قد يؤدي إلى اتخاذ إجراءات إدارية للحفاظ على جودة النقاش.
